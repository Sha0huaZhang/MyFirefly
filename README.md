# 来把她接回家！

**1.接她回家**  
在终端执行
```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Sha0huaZhang/MyFirefly/pick/pick_her.sh)"
```
或
```
curl -fsSL https://raw.githubusercontent.com/Sha0huaZhang/MyFirefly/pick/pick_her.sh | bash
```
或
```
curl -fsSL https://raw.githubusercontent.com/Sha0huaZhang/MyFirefly/pick/pick_her.sh | /bin/bash
```
萤宝就来了哦！(  `~/.local/MyFirefly` ）

如果你安装了MacWave （参见macwave.org ; https://github.com/Sha0huaZhang/MacWave )，那么也可以选择
```
wave install myfirefly
```
萤宝就来了哦！( `~/.local/MacWave/MyFirefly@{VERSION}` 或 `/opt/MacWave/Myfirefly@{VERSION}` 或 `/usr/local/MacWave/MyFirefly@{VERSION}` 等，取决于你安装MacWave的目录 )

如果你安装了LinuxWave （参见linuxwave.macwave.org ; https://github.com/Sha0huaZhang/LinuxWave )，那么也可以选择
```
wave install myfirefly
```
萤宝就来了哦！( `~/.local/LinuxWave/MyFirefly@{VERSION}` 或 `/opt/LinuxWave/Myfirefly@{VERSION}` 或 `/usr/local/LinuxWave/MyFirefly@{VERSION}` 或`/home/linuxwave/.linuxwave/` 等，取决于你安装LinuxWave的目录 )

**2.送她到家**

安装后，重启终端或执行
```
source ~/.zshrc
``` 
这样萤宝才进入了我们的家！
